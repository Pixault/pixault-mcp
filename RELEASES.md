# Pixault.Mcp — Release Notes

## 1.4.0 — 2026-08-06
- New organizational tools: `MoveImage` (re-file into a folder, metadata-only), `RenameImage` (display-name only), `TagImage` (append/replace keyword tags), `ListTags` (distinct project tag vocabulary with counts).
- New `GenerateArchive` tool: download a zip of images' originals to a local path (write-scoped, confined to the working directory).
- Upgraded to ModelContextProtocol 2.0. Consumes Pixault.Client 1.6.0.
